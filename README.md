# 《文心雕码》 (WenXin DiaoMa)

> **「以汉语言文学之文心，驭软件工程与 AI 之代码。」**
> 专为汉语言文学专业及人文社科学人打造的**软件工程概念映射与 AI 编程（Vibe Coding）交互式学习站**。

---

## 一、 核心立意

在 AI 结对编程时代，自然语言成为了新的高级编程语言。汉语言文学专业的同学在**文本结构、修辞逻辑、语境把控、叙事架构、版本校勘与目录学**上的专业训练，天然对应着软件工程与 AI 编程中最核心的工程化直觉：

- **文字与训诂学** ↔ **编程语言基础**（实词/虚词 ↔ 变量状态/函数/控制流；因文定义 ↔ 作用域 Scope 与上下文窗口）
- **文章与叙事学** ↔ **软件架构与组件化**（立意大纲 ↔ PRD 规格书；一段一意 ↔ 高内聚低耦合；词牌定格 ↔ UI 组件化 Props；用典 ↔ 开源库 `import`）
- **版本与目录学** ↔ **工程流与质量保障**（四库目录 ↔ 项目目录树；善本异文汇校 ↔ Git 版本控制；陈垣校勘四法 ↔ Debug 四步排障；删繁就简 ↔ 代码重构 Refactoring）
- **修辞与文体学** ↔ **AI 协同与契约**（公文格律 ↔ JSON Schema；书前《凡例》 ↔ `CLAUDE.md` / `.cursorrules` 系统规则；总纂覆校 ↔ Code Review 与验收测试）

---

## 二、 本地启卷方式（零第三方依赖，即开即用）

在项目根目录下运行：

```bash
npm run dev
```

随后在浏览器中访问：`http://127.0.0.1:3000`

---

## 三、 本项目“四库目录树”解析（你可以如何增补内容？）

本项目自身严格遵循**“史料数据（Data）与版面装帧（View）分离”**的高内聚低耦合原则。如果你想增补自己的词条或案例，只需像校改文档一样编辑 `src/data/` 下的文件：

```text
Chinese2Computer/
├── index.html               # 【书衣封面】网页主骨架与四卷容器
├── server.mjs               # 【书院驿站】零依赖本地开发服务器
├── package.json             # 【总目提要】项目元信息与启动口令
└── src/
    ├── data/                # 【史部 · 核心知识库】（可直接在此增补词条）
    │   ├── architecture.js  # 卷一：皇家书院 6 大节点、5 步请求流转、3 则故障断案
    │   ├── dictionary.js    # 卷二：四大分类共 16 则“汉 ↔ 软”双语对照词条
    │   ├── cases.js         # 卷三：《红楼梦》册页与《宋代笔记》工作台两大故事复盘
    │   └── prompts.js       # 卷四：6 式 AI 提示词法帖与定制工坊预设
    ├── styles/
    │   └── main.css         # 【集部 · 装帧设色】新中式宣纸暖白与松烟夜读双主题样式
    └── main.js              # 【子部 · 机关流转】四卷交互逻辑与微沙盒渲染
```
