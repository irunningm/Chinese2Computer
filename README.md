# 《文心雕码》 (WenXin DiaoMa)

> **「以汉语言文学之文心，驭软件工程与 AI 之代码。」**
> 专为汉语言文学专业及人文社科学人打造的**软件工程概念映射与 AI 编程（Vibe Coding）交互式学习站**。

---

## 一、 核心立意

在 AI 结对编程时代，自然语言成为了新的高级编程语言。汉语言文学专业的同学在**语法分析、谋篇布局、改稿统稿、引文核校与编辑审读**上的训练，天然对应着软件工程与 AI 编程中最核心的工程化直觉：

- **现代汉语·语法篇** ↔ **编程语言基础**（主谓宾 ↔ 对象/函数/参数；复句 ↔ 条件/事件/循环；病句 ↔ 三类报错；语境与指代 ↔ 作用域与上下文窗口）
- **写作学·谋篇布局** ↔ **软件架构与组件化**（底本与版式 ↔ 数据与视图分离；立主脑、列提纲 ↔ PRD；一章一义 ↔ 高内聚低耦合；活字与词牌 ↔ UI 组件与 Props）
- **论文写作·改稿篇** ↔ **工程流**（论文文件夹 ↔ 项目目录树；修订留痕 ↔ Git；善假于物 ↔ 开源库；统稿删繁 ↔ 重构）
- **AI 沟通·审稿篇** ↔ **AI 协同与验收**（投稿体例 ↔ `AGENTS.md` / `CLAUDE.md` 规则文件；登记表 ↔ JSON；夹注与舞台提示 ↔ 代码注释；主编审样刊 ↔ 边界验收）

全局全景一卷采用统一的主比喻——**一座闭架借阅的图书馆**：阅览大厅 = 前端，索书单 = API，借阅台后的馆员 = 后端，书库与卡片目录 = 数据库，修订档案 = Git。

> [!NOTE]
> **引文约定**：站内带引号的古今引文均应可回原书核对；概括转述一律标注“（大意）”或“（示意）”。实战案例中的人物为教学用虚构情境，词频数字为示例数据。

## 二、 本地启卷方式（零第三方依赖，即开即用）

在项目根目录下运行：

```bash
npm run dev
```

随后在浏览器中访问：`http://127.0.0.1:3000`

---

## 三、 项目目录树（你可以如何增补内容？）

本项目遵循**“文字资料（Data）与版面代码（View）分离”**的原则。如果你想增补词条、案例或修改导语，只需像校改文档一样编辑 `src/data/` 下的文件：

```text
Chinese2Computer/
├── index.html               # 网页主骨架（顶栏、五卷导航、底部抽屉容器）
├── server.mjs               # 零依赖本地开发服务器
├── package.json             # 项目元信息与启动口令
├── AGENTS.md                # 给 AI 助手的项目规则（CLAUDE.md 引用它）
└── src/
    ├── data/                # 【文字资料】可直接在此增补、校改
    │   ├── copy.js          # 各卷顶部导语文案
    │   ├── architecture.js  # 卷一：6 大模块、5 步请求流转、3 道诊断小测
    │   ├── dictionary.js    # 卷二：四大分类“汉 ↔ 码”对照词条（数量以数据为准）
    │   ├── techstacks.js    # 卷三：6 种产品形态、选型罗盘、四步上手路线
    │   ├── cases.js         # 卷四：红楼梦花签、宋代笔记检索台、贬谪诗文语料三大案例
    │   └── prompts.js       # 卷五：6 个 AI 提示词模板与新项目生成器预设
    ├── core/                # 【公共机关】
    │   ├── state.js         # 全站状态（当前卷、筛选条件、卡片翻转等）
    │   ├── router.js        # 按当前卷渲染对应视图
    │   ├── sheet.js         # 底部详情抽屉
    │   └── utils.js         # 转义、高亮、复制、导语卡片
    ├── views/               # 【五卷版面】每卷一个文件
    │   ├── arch.js  dict.js  stacks.js  cases.js  prompts.js
    ├── styles/
    │   └── main.css         # 宣纸暖白与夜读双主题样式
    └── main.js              # 入口：启动应用、绑定全局按钮
```
